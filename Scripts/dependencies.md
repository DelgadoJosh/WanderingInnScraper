# Dependencies

This python script has a few dependencies. 

Dependencies:
* Requests - For the web requests
* Beautiful Soup 4 - For parsing the html in Python 3
* tkinter (Usually included with Python) - For the GUI
* cloudscraper - For bypassing Cloudflare anti-bot checks

## How to Install dependencies
Run the following commands:

1. `pip install requests`
2. `pip install beautifulsoup4`
3. `pip install cloudscraper`
